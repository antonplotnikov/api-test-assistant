# Помощник API-тестирования

[![tests](https://github.com/antonplotnikov/api-test-assistant/actions/workflows/tests.yml/badge.svg)](https://github.com/antonplotnikov/api-test-assistant/actions/workflows/tests.yml)

Веб-страница для тестирования API на основе Postman-коллекций. Работает в браузере без сборки и без сервера приложения.

**Онлайн:** https://antonplotnikov.github.io/api-test-assistant/

## Запуск

```bash
cd ~/api-test-assistant
python3 -m http.server 8765
# открыть http://localhost:8765
```

Файл `index.html` можно открыть и напрямую, но тогда не загрузится кнопка «Демо», а часть API отклонит запросы со страницы `file://`.

Для начала нажмите **Импорт → Загрузить демо**. Подгрузятся коллекция, окружение и OpenAPI для jsonplaceholder.typicode.com.

## Вкладки

| Вкладка | Что делает |
|---|---|
| **Коллекция** | Импорт и экспорт Postman Collection v2.1 и Environment, OpenAPI (JSON/YAML), cURL. Файлы можно перетащить на страницу. Редактор запроса: Params (синхронизированы с URL), заголовки, тело, авторизация (наследуется от папки и коллекции), скрипты, конструктор проверок. Под URL видно, какие `{{переменные}}` заданы, а какие нет. Отправка — Enter в строке URL или ⌘/Ctrl+Enter. |
| **Запуск и проверки** | Прогон коллекции или папки: итерации, файл данных CSV/JSON (`pm.iterationData`), задержка, остановка на первом падении. Сравнение с прошлым прогоном (регрессии, починившиеся, замедления, смена кода ответа), история последних 15 прогонов, кнопка «Перезапустить упавшие». Отчёты: HTML (самодостаточный файл), JUnit XML, Markdown. Команда для Newman / Postman CLI. |
| **Анализ падений** | Вероятная причина для каждого падения (401/403/404/4xx/5xx, таймаут, CORS/сеть, неподставленные переменные, контракт, ошибки скриптов), шаги проверки и баг-репорт в Markdown с cURL. Токены в отчёте маскируются. |
| **Генерация кейсов** | Из выбранного запроса строит позитивный кейс, кейсы на авторизацию, тело, обязательность и типы полей, граничные значения, параметры пути и query, спецсимволы и mass assignment. Кейсы добавляются в коллекцию папкой с готовыми `pm.test`. |
| **Нагрузка** | N запросов при C параллельных: p50/p90/p95/p99, RPS, процент ошибок, графики. |
| **Контракт** | Сверяет ответы с OpenAPI 3 / Swagger 2: типы, required, форматы, enum, задокументированные коды. Строгий режим показывает необъявленные поля. Показывает покрытие операций. Умеет создать коллекцию или моки из спецификации. |
| **Моки** | Правила «метод + путь → статус / заголовки / тело / задержка», а также имитация сетевой ошибки. Есть быстрые сбои: 500, 503, 429, таймаут, битый JSON. Экспорт в коллекцию с примерами для Postman Mock Server. |
| **Безопасность** | Пассивный сканер полученных ответов по OWASP API Security Top 10: стектрейсы и SQL-ошибки, пароли/ключи/номера карт в ответах, персональные данные в списках, HTTP вместо HTTPS, секреты в URL, кеширование приватных ответов, заголовки безопасности, отсутствие rate limit (по нагрузочному прогону). Активные проверки — группа «Безопасность» в генерации кейсов: IDOR, подмена метода, токен в query, заголовки подмены. |
| **✦ ИИ-ассистент** | Claude видит выбранный запрос и ответ, падения прогона, коллекцию и OpenAPI. Умеет объяснить падение, написать `pm.test` (кнопка «Добавить в Tests»), предложить сценарии, составить баг-репорт, сделать ревью покрытия. **Кейсы из требований:** вставьте user story или текст задачи и получите готовые запросы с проверками, которые добавляются в коллекцию. Кнопки «✦ Спросить ИИ» есть в панели ответа, в анализе падений и в сканере. |

**Сравнение окружений** (вкладка «Запуск»): одни и те же запросы уходят в два окружения, ответы сравниваются по полям (значение, тип, пропавшие и новые поля, длина массивов). Меняющиеся поля (`id`, даты) можно исключить. По умолчанию запускаются только GET/HEAD.

### ИИ-ассистент: ключ и приватность

- Нужен API-ключ Anthropic (platform.claude.com → Settings → API keys). Расход идёт с вашего аккаунта, выбор модели — в настройках ассистента. По умолчанию стоит Claude Opus 5.5, также доступны Sonnet 5.5 и Haiku 5.5.
- Запросы идут из браузера напрямую в API Anthropic через официальный SDK (`@anthropic-ai/sdk@1.5.0`). Ключ не сохраняется, пока вы не отметите «Запомнить ключ», и не попадает в экспорт. На общем компьютере используйте отдельный ключ с лимитом расходов.
- Перед отправкой токены, пароли, JWT, ключи и значения секретов окружения заменяются на `••••`, тела ответов обрезаются до 8000 символов. Что именно уйдёт, видно по кнопке «Показать, что отправится».
- Для Opus 5.5 и Sonnet 5.5 включён серверный fallback (`fallbacks: "default"`): если модель откажется отвечать, запрос автоматически переходит на запасную модель, и в чате это отмечается.

### Проверки без кода

Конструктор на вкладке «Проверки» добавляет обычный код `pm.test`, поэтому коллекция остаётся совместимой с Postman и Newman. Доступны проверки:
- статус, время ответа, заголовок, JSON-путь, текст в теле;
- сохранение значения в переменную (например, токен после логина);
- **схема из ответа**: фиксирует структуру;
- **эталон**: фиксирует сами значения. Через запятую укажите поля, которые меняются от запуска к запуску (`id, createdAt`). При падении проверка показывает, что именно изменилось: `$.title`, «поле пропало», «новое поле», длина массива.

## Скрипты Postman

Скрипты коллекции, папок и запросов выполняются в порядке Postman. Поддерживается:
- `pm.test` и `pm.expect` (подмножество chai);
- `pm.response.to.have.status/header/jsonBody/jsonSchema`, `pm.response.to.be.ok`;
- `pm.environment`, `pm.collectionVariables`, `pm.variables`, `pm.iterationData`;
- `pm.execution.setNextRequest` и `console.log`;
- legacy-синтаксис `tests[]` и `postman.setEnvironmentVariable`.

**Не поддерживается:** `pm.sendRequest`, `require()`, cookies. Такие коллекции запускайте через `npx newman run …` или `postman collection run …`. Страница помечает эти места как «не поддерживается», а не как падение API.

Скрипты выполняются прямо на странице, как в Postman. Импортируйте только свои или доверенные коллекции.

## Ограничения

- **CORS.** Браузер отправит запрос только к API, которое разрешает CORS. Если видите «Сетевая ошибка», есть три варианта: настроить CORS на тестовом стенде, указать свой прокси в настройках или запустить коллекцию через Newman / Postman CLI.
- **Нагрузка.** Браузер держит около 6 соединений на хост по HTTP/1.1. Это быстрая оценка, а не замена k6 или JMeter.
- **Хранение данных.** Коллекция, окружения, моки, настройки и история прогонов (только статусы и время, без тел ответов) хранятся в `localStorage` этого браузера. Значения секретов (тип `secret` или имена вроде token/password/key) не сохраняются и в экспорт по умолчанию не попадают.
- Внешние `$ref` в OpenAPI не разрешаются. Для YAML парсер загружается с cdnjs, поэтому нужен интернет.

## Тесты

```bash
npm ci                  # один раз: puppeteer-core для браузерных тестов
npm test                # логика без сети
npm run test:network    # + реальные запросы к jsonplaceholder
npm start               # в другом терминале, затем:
npm run test:e2e        # сценарии в Chrome: все вкладки, мобильная ширина, тёмная тема
```

e2e поднимает локальный mock-сервер Claude API (SSE-стриминг) на порту 8766, поэтому реальный API Anthropic в тестах не вызывается и деньги не тратятся. Тест проверяет заголовки SDK, модель, fallbacks, effort, structured outputs и то, что секреты не уходят в запрос. SDK при этом грузится с cdn.jsdelivr.net, так что нужен интернет.

GitHub Actions запускает все три набора на каждый push и pull request.
