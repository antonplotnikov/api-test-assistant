Отчёт:

Сравнение окружений

Одни и те же запросы уходят в два окружения (например, dev и stage), ответы сравниваются по полям: так видно, что изменилось при выкладке и где окружения разъехались.

Анализ падений

Разбор упавших запросов последнего прогона: вероятная причина, что проверить и готовый баг-репорт. Анализ — правила по коду ответа, проверкам и контракту, без отправки данных куда-либо.

Генерация тест-кейсов

Берёт запрос из коллекции и строит позитивные, негативные и граничные кейсы с проверками. Кейсы добавляются в коллекцию отдельной папкой — их можно сразу запустить или экспортировать в Postman.

Группы кейсов

Нагрузочный прогон

Запускайте только на своих тестовых стендах. Браузер держит ~6 одновременных соединений на хост (HTTP/1.1), поэтому это оценка «под небольшой нагрузкой», а не замена k6/JMeter/Postman Performance.

Моки

Когда моки включены (кнопка в шапке), запросы со страницы сначала ищут подходящее правило. Путь: /users/:id, /files/* или полный URL. В теле доступны {{path.id}}, {{request.body}}, {{$guid}}, {{$timestamp}}.

Быстрая имитация сбоя для выбранного запроса

Сканер безопасности

Пассивная проверка уже полученных ответов по мотивам OWASP API Security Top 10: утечки стектрейсов и секретов, персональные данные, транспорт, заголовки, кеширование, rate limit. Сканер ничего дополнительно не отправляет. Для активных проверок (IDOR, подмена метода, токен в URL) сгенерируйте кейсы группы «Безопасность» и запустите их на тестовом стенде.

Подключение к Claude

Дополнительно

Запросы идут из браузера напрямую в API Anthropic по вашему ключу и оплачиваются с вашего аккаунта. Ключ не попадает в экспорт; без галочки «Запомнить» он живёт до перезагрузки страницы. Создать ключ: platform.claude.com → Settings → API keys. На общем компьютере используйте отдельный ключ с лимитом расходов.

Что видит ассистент

Перед отправкой токены, пароли, JWT и значения секретов окружения заменяются на ••••. Тела ответов обрезаются до 8000 символов.

Ассистент

Тест-кейсы из требований

Вставьте user story, текст задачи или фрагмент спецификации. Claude составит кейсы с учётом вашей коллекции и OpenAPI, их можно сразу добавить в коллекцию и запустить.

Импорт

Postman Collection v2.1, Postman Environment, OpenAPI (JSON/YAML) или команда cURL. Можно выбрать несколько файлов сразу или просто перетащить их на страницу.

Экспорт

По умолчанию значения переменных типа secret и с именами вроде token/password/key экспортируются пустыми.

Код автотестов

Перенос в автотесты: запросы и проверки переводятся в код, переменные — в конфиг (секреты читаются из переменных окружения ОС). Что не удалось перевести автоматически, остаётся с пометкой TODO и исходным кодом Postman.


  




  
Настройки

  
  
  
  
Браузер отправляет запросы только к API, которые разрешают CORS. Прокси пишется перед URL; {url} заменяется на закодированный адрес. Не используйте чужие публичные прокси для запросов с токенами.
